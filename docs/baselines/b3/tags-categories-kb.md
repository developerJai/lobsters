# Tags & Categories

> A comprehensive guide to Tags & Categories.

---

## What is Tags & Categories?

Tags are short topic labels attached to every story on the site, and categories are the broader groups those tags are organized into. Together they let you browse stories by subject, discover related topics, and hide topics you're not interested in — all from one directory page.

---

## Key Capabilities

- Browse every tag, grouped under category headings with a short description of each
- Open all stories for a tag, or combine several tags in one view (`/t/tag1,tag2`)
- Open all stories for a category, or several at once (`/categories/foo,bar`)
- Filter out stories by tag so they stop appearing in your feeds — even without an account
- See which tags are retired ("inactive") and which ones you currently filter
- Get a machine-readable list of all tags if you build tools against the site

---

## How It Works

1. **Staff curate the vocabulary** — administrators and moderators create categories and tags; each tag gets a name (up to 25 characters), a one-line description, and a home in exactly one category.
2. **Submitters label stories** — when a story is submitted, the author picks tags for it. A few special tags can only be applied by moderators, and some tags are unavailable to brand-new accounts (you get a clear error if you try).
3. **Readers browse the directory** — the Tags page lists every category alphabetically with its tags, each linked to a feed of matching stories.
4. **Readers tune their feeds** — from the filters page you choose tags to hide; stories carrying those tags disappear from your feeds. Tags you filter are marked "filtered" in the directory.
5. **Tags retire, never vanish** — when a tag outlives its usefulness it is marked *inactive*: it can't be used on new stories but stays on old ones, so history remains readable.
6. **Every change is public** — any creation or edit of a tag or category is recorded in the public moderation log with what changed and who changed it.

## Common Questions

**Q: Do I need an account to filter out tags?**
A: No. You can filter stories by tag even when logged out; the directory page says so right at the top. An account keeps your filters tied to you rather than your browser.

**Q: Can a tag belong to more than one category?**
A: No. Every tag lives in exactly one category. If a topic spans areas, it will be one tag in the category that fits best.

**Q: Why can't I add a certain tag to my story?**
A: Three possibilities: the tag is privileged (only moderators may apply it), it is inactive (retired from new stories), or your account is too new for that particular tag. You'll see an error message rather than a silent failure.

**Q: What does the "inactive" label on a tag mean?**
A: The tag has been retired: it can no longer be used on new stories, but older stories keep it so their labels still make sense.

**Q: Can I read two topics in one list?**
A: Yes — visit `/t/tag1,tag2` with the tags you want, separated by commas. The same trick works for whole categories at `/categories/foo,bar`.

**Q: Do tags affect which stories appear on the front page?**
A: Slightly. Each tag can carry a small ranking adjustment (a boost or a penalty), so stories with certain tags may rank a bit higher or lower than they otherwise would.

**Q: Who decides which tags exist?**
A: Site administrators and moderators. You can't create tags yourself, but every change staff make is visible in the public moderation log.

**Q: Is there a way to see tags related to one I like?**
A: The site computes up to eight tags that most often appear on the same stories as a given tag (the generic catch-all tag and media tags are excluded from these suggestions).

## Tips & Best Practices

- Start at the Tags page when exploring: descriptions tell you exactly what each tag is for before you dive into its stories.
- Combine complementary tags with the comma trick (`/t/tag1,tag2`) to build your own custom feed without any settings.
- Filter early: if a topic annoys you, one click on the filters page removes it from every feed — you don't need an account.
- Check the "filtered" markers on the Tags page occasionally; it's the quickest inventory of what you're hiding.
- When submitting a story, prefer the most specific tags that genuinely fit; privileged and retired tags will be rejected with an explanation.

---

## Limitations & Important Notes

- Tags and categories are staff-managed; readers cannot create or rename them.
- Tags are never deleted, only retired — expect to see *inactive* entries in the directory.
- A handful of tags are moderator-only, both for applying to stories and for filtering.
- Some tags are off-limits to brand-new accounts when submitting.
- Tag and category web addresses are their names, so if staff rename one, old links stop working.
- Filtering hides stories from feeds; it does not remove the tag from the directory page.
